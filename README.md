🧠 Jogo da Memória – Android (Java)

Um jogo da memória desenvolvido em Android Studio, utilizando Java e GridLayout, com cartas que viram, combinam entre si e contabilizam a pontuação do jogador.

📱 Sobre o Projeto

O jogo consiste em um tabuleiro com cartas viradas para baixo.
O jogador deve tocar em duas cartas e tentar encontrar pares iguais.

O projeto foi desenvolvido para fins didáticos, praticando:

Programação orientada a objetos (Java)

Manipulação de Views e eventos de toque

Atualização dinâmica da interface

Utilização de recursos gráficos (imagens)

Lógica de controle de jogo

🛠️ Tecnologias Utilizadas

Android Studio

Java

XML (layouts)

GridLayout

Resources drawables para imagens das cartas

🎮 Funcionalidades

✔️ Embaralhamento das cartas
✔️ Sistema de virar cartas
✔️ Verificação automática de par
✔️ Bloqueio temporário para impedir múltiplos cliques
✔️ Reinício do jogo
✔️ Contagem de tentativas ou pontos (dependendo da sua versão)
